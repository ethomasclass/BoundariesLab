# Fault Lines: Boundary Survey Lab

An interactive AP Human Geography lab for Topics 4.4 (Defining Political Boundaries) and 4.5 (The Function of Political Boundaries).

Student pairs travel to a warm-up stop and eight real borders in four matchups. At each stop they read a short field briefing, peel back the layers of a hex map, tag clues in a border scene, and take seismograph readings: a surface reading (1 Stable to 5 Major Quake) for each side, the stored pressure along the line, and its main pressure source. Then they rank boundary types on a hazard map, draw the borders of a new continent, sign treaties, predict how each line will hold, and face 50 years of aftershocks. The lab ends with an exit FRQ and a printable report.

| Matchup | Stops |
|---|---|
| Warm-up | The relic line (Berlin) |
| A · Who drew the line? | 1. The Andes · 2. Berlin 1884, then Africa today |
| B · Lines and culture | 3. The 49th parallel · 4. Partition |
| C · Who gets to cross? | 5. The Korean DMZ · 6. Schengen |
| D · Within and below | 7. The Caucasus · 8. Iraq and Kuwait |

## Files

- `index.html`: the page (served by GitHub Pages)
- `data.js`: all lab content (stories, terms, maps, clues, aftershock cards). Edit text here.
- `app.js`: how the lab works
- `style.css`: the look
- `img/`: Google Flow artwork. Until an image exists, the page shows a dashed placeholder that names the file it expects. The full prompt list is in the planning spreadsheet (Flow Prompts tab).

## Notes for teachers

- Student work saves in each browser, so a refresh does not lose progress. "Start over" on the Report screen erases it.
- Add `?unlock=1` to the address to open every screen without finishing the stops (for previewing or demos).
- Timing: about 53 minutes for the warm-up and matchups A and B, 46 for C, D and the hazard map, and 55 for the build, aftershocks and exit FRQ.
